# 배선도

## 전원 구조

```text
KC 12V/3A 어댑터
        |
        +---- 2A 퓨즈 ---- MOSFET CH1 ---- 12V LED 바
        |
        +---- DC-DC 5V/3A ----+---- XIAO USB-C 또는 5V 입력
                               +---- MOSFET CH2 ---- 5V 펌프
```

모든 저전압 GND는 공통으로 연결합니다. 12V 양극과 5V 양극을 서로 직접 연결하면 안 됩니다.

## XIAO 핀 배정

| XIAO 핀 | 연결 | 비고 |
|---|---|---|
| D0 | 플로트 스위치 | `INPUT_PULLUP`, 다른 쪽은 GND |
| D1 | 펌프 MOSFET 신호 | 3.3V 로직 호환 모듈만 사용 |
| D2 | LED MOSFET 신호 | PWM 가능 |
| D4/SDA | SHT40 SDA | I2C |
| D5/SCL | SHT40 SCL | I2C |
| 3V3 | 센서 VCC | 펌프 연결 금지 |
| GND | 센서/MOSFET 공통 GND | 스타 접지 권장 |

카메라는 Sense 확장보드에 이미 연결되어 있으므로 별도 배선하지 않습니다.

## 안전 규칙

- 펌프를 ESP32 GPIO에 직접 연결하지 않습니다.
- 펌프가 브러시 모터라면 MOSFET 모듈의 플라이백 다이오드 유무를 확인합니다.
- 전자함으로 들어오는 케이블은 아래로 한 번 처지게 해 물방울 고리(drip loop)를 만듭니다.
- 플로트 스위치가 LOW WATER를 감지하면 자동 펌프를 금지합니다.
- 펌프 한 번의 최대 작동은 30초, 하루 누적은 5분으로 제한합니다.
